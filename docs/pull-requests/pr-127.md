Closing: this digest bump can't land here.

`.github/workflows/codeql.yml` and `.github/workflows/scorecard.yml` are devkit-managed scaffold files. devkit 1.6.0 pins `github/codeql-action` at `d1ba80a`, so the `scaffold-drift` gate (devkit #1295) rejects any consumer-side change to those pins — the digest is advanced upstream by devkit's own Renovate and ships with a devkit release.

This PR should not have been opened: devkit 1.6.0 added a `packageRules` entry disabling updates to managed workflow files (vig-os/devkit#1332), but it lives in `.github/renovate-default.json`, which Renovate resolves from the **default branch**. `main` is still at `DEVKIT_VERSION=1.2.1` (66 commits behind `dev`), so Renovate is running the pre-1.6.0 preset while CI enforces the 1.6.0 scaffold. Same cause as #123.

Fix is either promoting `dev` to `main`, or mirroring the exclusion rule into this repo's own `renovate.json` (read from the `dev` base branch, so it applies immediately).
